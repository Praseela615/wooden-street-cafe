# Wooden Street Café

A modern responsive café website built with HTML, CSS and vanilla JavaScript.

## Features

- Responsive desktop/tablet/mobile layout
- Biophilic café concept
- Book Nook
- Coworking sanctuary
- Local art gallery
- Interactive community wall using localStorage
- Menu categories and live search
- Add-to-order cart using localStorage
- Dark mode
- Gallery filters and lightbox
- Customer testimonials slider
- Reservation form with browser validation and date restriction
- Newsletter UI
- Smooth navigation and hover/scroll-friendly UI
- GitHub Pages compatible

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages

This is a static HTML/CSS/JavaScript project, so it can be deployed directly through GitHub Pages.

1. Create a public GitHub repository.
2. Upload all project files, keeping `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for the deployment to finish.

The website uses remote Unsplash images for visual content, so an internet connection is needed for those images.

## Important

The reservation and ordering interfaces are front-end demos. They do not connect to a real restaurant database, payment gateway, email server, or reservation system.
